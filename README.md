# RC 탱크 프로젝트(Panzer IV)

Bluepad32를 이용한 게임패드 조작 RC 탱크입니다. ESP32-IDF(v5.4.3) 기반으로 개발되었습니다.

PCB는 KingTiger용을 사용합니다.

## 주요 기능

- **게임패드 연결**: Bluepad32를 통한 블루투스 게임패드 연결 및 상태 LED/진동 피드백
- **트랙 제어**: 좌측 스틱 Y축(좌측 트랙), 우측 스틱 Y축(우측 트랙) 독립 제어 (DRV8833, MCPWM, 엑스포 곡선, 가감속 램프, 대회전 감속)
- **터렛 제어**: D-PAD 좌우로 터렛 회전 (DRV8833, MCPWM, 최대 속도 100% 듀티)
- **포 마운트 제어**: D-PAD 상하로 포신 상하 이동 (SG90 서보, 80~110도, 초당 10도)
- **포신 발사**: B 버튼 클릭 시 포신 반동(서보 0->60->0), LED 점등, 발사 효과음 및 게임패드 진동 발생 (트랙 후진 반동 200ms 동기화)
- **기관총 발사**: A 버튼 클릭 시 기관총 LED 깜빡임(500ms), 효과음 및 게임패드 진동 발생 (반응성 개선을 위해 지연 시간 300ms로 단축)
- **헤드라이트**: Y 버튼으로 헤드라이트 ON/OFF 토글
- **볼륨 조절**: L1 버튼으로 감소, R1 버튼으로 증가 (NVS 저장, 10-30 범위)
- **대기 상태 알림**: 게임패드 연결 전/해제 후에는 30초마다 엔진 IDLE 효과음을 1회 재생하여 상태 알림 (연결 중에는 IDLE 소리 중지)
- **설정 초기화**: Select + Start 버튼을 3초간 누르면 볼륨 설정 초기화 및 재시작

## 하드웨어 구성

### ESP32 핀 맵

| ESP32 핀 | 기능 | 설명 |
| :--- | :--- | :--- |
| **GPIO 4** | 후미등 LED | Backlight |
| **GPIO 5** | 헤드라이트 LED | Headlight (Y 버튼 토글) |
| **GPIO 13** | 포 마운트 서보 | SG90 서보 - 포신 상하 이동 (80~110도) |
| **GPIO 16** | 기관총 LED | MG LED (A 버튼 클릭 시 깜빡임) |
| **GPIO 17** | 포신 LED | Gun LED (B 버튼 클릭 시 점등) |
| **GPIO 21** | 터렛 IN2 | DRV8833 - 터렛 회전 (MCPWM) |
| **GPIO 22** | 터렛 IN1 | DRV8833 - 터렛 회전 (MCPWM) |
| **GPIO 23** | 사운드 TX | DFPlayer Mini UART TX |
| **GPIO 25** | 우측 트랙 IN2 | DRV8833 - 우측 트랙 (MCPWM) |
| **GPIO 26** | 좌측 트랙 IN2 | DRV8833 - 좌측 트랙 (MCPWM) |
| **GPIO 27** | 좌측 트랙 IN1 | DRV8833 - 좌측 트랙 (MCPWM) |
| **GPIO 32** | 포신 서보 | 포신 반동 (Recoil) 제어 |
| **GPIO 33** | 우측 트랙 IN1 | DRV8833 - 우측 트랙 (MCPWM) |

### 모터 드라이버 (DRV8833) 연결

#### 트랙 드라이버
- **AIN (27, 26)**: 좌측 트랙 모터 (MCPWM)
- **BIN (33, 25)**: 우측 트랙 모터 (MCPWM)

#### 터렛 드라이버
- **AIN (22, 21)**: 터렛 회전 모터 (MCPWM, 최대 속도 100% 듀티)

### 서보 모터
- **GPIO 32**: 포신 반동 서보 (B 버튼 시 0도 -> 60도 -> 0도 동작)
- **GPIO 13**: 포 마운트 서보 SG90 (D-PAD 상하, 80~110도 범위, 초기 90도)

### 사운드 모듈 (DFPlayer Mini)
- **TX (GPIO 23)**: 모듈의 RX 핀에 연결하여 UART 제어 (9600bps)
- **RX (NC)**: 현재 수신 핀이 연결되지 않아 모듈 피드백(재생 종료 알림 등) 대신 타이머/하드웨어 루프 명령어로 상태 제어

## 게임패드 조작법

| 조작 | 기능 | 상세 동작 |
| :--- | :--- | :--- |
| **좌측 스틱 Y** | 좌측 트랙 | 위(전진), 아래(후진) |
| **우측 스틱 Y** | 우측 트랙 | 위(전진), 아래(후진) |
| **D-PAD 좌/우** | 터렛 회전 | 좌우 회전 (MCPWM, 최대 속도) |
| **D-PAD 상/하** | 포 마운트 | 상하 이동 (SG90 서보, 80~110도) |
| **A 버튼** | 기관총 발사 | 효과음 재생 + MG LED 깜빡임 |
| **B 버튼** | 주포 발사 | 효과음 재생 + Gun LED 점등 + 서보 반동 |
| **Y 버튼** | 헤드라이트 | ON / OFF 토글 |
| **L1 / R1** | 볼륨 조절 | 볼륨 감소 / 증가 (NVS 자동 저장) |
| **Select + Start** | 시스템 초기화 | 3초간 입력 시 설정 초기화 및 재부팅 |

## 소프트웨어 구조

### 주요 컴포넌트 (`components/rctank/`)
- `rctank_motor`: MCPWM을 이용한 트랙 및 터렛 제어
- `rctank_servo`: LEDC를 이용한 포신 반동 서보 및 포 마운트(SG90) 서보 제어
- `rctank_led`: 각종 LED 상태 제어
- `rctank_dfplayer`: DFPlayer Mini 제어 및 효과음 재생
- `rctank_storage`: NVS를 이용한 볼륨 및 설정값 저장

### 플랫폼 로직 (`main/my_flatform.c`)
- Bluepad32 이벤트 핸들링 및 게임패드 입력 맵핑
- 발사 시퀀스 지연 보정 (Sound 재생 시점과 하드웨어 동작 동기화)
- 대회전 감속: 좌우 트랙 속도 차이가 클 때 전체 속도 비례 감소 (`TURN_SLOWDOWN_FACTOR`)

### 트랙 속도 제어 (`components/rctank/rctank_motor.c`)
- **엑스포 곡선**: 스틱 저속 구간(0~90%)에서 모터 속도를 완만하게, 고속 구간에서 급격하게 매핑하여 미세 조향 응답성 향상
- **가감속 램프**: 10ms 주기로 현재 속도를 목표 속도로 점진적 변화 (가속 600/sec, 감속 1000/sec)
- **최소 기동 속도**: 정지 상태에서 모터 기동 시 최소 토크 확보를 위한 오프셋 적용
- **감속 제자리 정지**: 감속 중 최소 속도 이하로 떨어지면 즉시 정지하여 모터 험 노이즈 방지

## 속도 제어 설정값

| 상수 | 값 | 위치 | 설명 |
| :--- | :--- | :--- | :--- |
| `AXIS_DEADZONE` | 60 | `my_flatform.c` | 조이스틱 데드존 (이 값 이하 무시) |
| `AXIS_MAX` | 512 | `my_flatform.c` | 조이스틱 최대 축 값 |
| `TURN_SLOWDOWN_FACTOR` | 60 | `my_flatform.c` | 대회전 시 최소 속도 비율 (60 = 60%) |
| `TRACK_DECEL_STEP` | 16 | `rctank_motor.c` | 10ms 당 감속 단계 (약 400ms 내 정지) |
| `TRACK_ACCEL_STEP` | 6 | `rctank_motor.c` | 10ms 당 가속 단계 (약 1000ms 내 최대 속도) |
| `TRACK_MIN_SPEED` | 448 | `rctank_motor.c` | 모터 최소 기동 속도 오프셋 |
| `TRACK_STICK_THRESHOLD` | 460 | `rctank_motor.c` | 엑스포 곡선 저속/고속 구간 경계 (90%) |
| `TRACK_EXPO_THRESHOLD` | 178 | `rctank_motor.c` | 경계값에서의 모터 속도 (약 35%) |

## 개발 환경 설정

1. **ESP-IDF v5.4.3** 설치
2. 프로젝트 루트의 `env.bat`를 실행하여 환경 변수 설정 (Windows)
3. `idf.py build` 명령으로 컴파일
4. `idf.py flash monitor` 명령으로 업로드 및 로그 확인
